# Kısa Çizgi ve Yay Ayraç Sunumu

Türk Dili ve Edebiyatı dersi için Kısa Çizgi (-) ve Yay Ayraç ( ) noktalanma işaretlerinin kurallarını, kullanımlarını ve örneklerini anlatan modern, etkileşimli React sunum uygulaması.

## Özellikler

- **10 Kapsamlı Slayt**:
  - Konu tanıtımı ve temel kavramlar
  - Kısa çizginin tanımı ve örnekleri
  - Kısa çizginin kullanım alanları (satır sonu, kök-ek, sayı aralığı, kavramlar arası)
  - **Mini Oyun 01**: Çoktan seçmeli kural yakalama testi
  - Kısa tekrar: Karıştırılan örnekler ve doğru yazımlar
  - Yay ayracın tanımı ve edebiyat örnekleri
  - Yay ayracın görevleri (açıklama, tarih, çevirmen, alıntı)
  - Kısa çizgi ile yay ayraç karşılaştırması
  - **Mini Oyun 02**: Cümleleri ait oldukları noktalama işareti kutularına sürükle-bırak veya tıkla-yerleştir oyunu
  - Kapanış ve ders özeti
- **Klavye & Dokunmatik & Fare Desteği**:
  - `→` / `Boşluk` (Space): Sonraki slayt
  - `←`: Önceki slayt
  - Dokunmatik ekranlarda sağa / sola kaydırma (swipe)
  - Masaüstünde fare ile sürükleme
- **Tam Ekran Modu**:
  - Sunum esnasında projeksiyon ve akıllı tahta uyumlu tek tıkla tam ekran açma/kapama
- **Üst İlerleme Çubuğu & Nokta Navigasyonu**:
  - Hangi slaytta olunduğunu dinamik gösteren parıltılı ilerleme çubuğu ve tıklanabilir slayt noktaları

## Çalıştırma

```bash
npm install
npm run dev
```
Dev sunucusu `http://0.0.0.0:3000` adresinde çalışacaktır.
